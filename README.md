# cj_gpt_pet

ChatGPT custom pet: **파란 프로펠러**.

## Files

- `blue-propeller/pet.json` — pet manifest
- `blue-propeller/spritesheet.webp` — v2 animated spritesheet (1536×2288)
- `blue-propeller.zip` — ready-to-copy package
- `preview.gif` — animation preview

## Install

1. Download `blue-propeller.zip`.
2. Extract it so the `blue-propeller` folder contains `pet.json` and `spritesheet.webp`.
3. In Codex, open **Settings → Pets → Open folder** and copy that folder into the pets directory.
4. Refresh the pet list and select **파란 프로펠러**.
